# YouTube Shorts

Write or extract vertical, short-form (under 60s) video content optimized for Shorts' watch behavior.

## Modes

1. **Extract clips from long-form content** — given a script/transcript, identify 3–5 moments that work as standalone Shorts: a strong claim, a punchy story beat, a surprising fact, a quick tip. For each, give the exact start/end points (quote the lines) and note what trimming is needed to make it stand alone without the surrounding context.
2. **Write a new Shorts script** — given a topic, write a full script following Shorts-specific structure:
   - **First 1–2 seconds**: the hook must work with no setup — state the payoff, the shocking claim, or show the result immediately. No "hey guys" intros.
   - **Body**: single idea only, fast-paced, one beat flowing directly into the next, no filler.
   - **Loop-friendly ending**: where possible, end in a way that flows back into the opening (visually or narratively) to encourage rewatches.
   - Keep total spoken content to roughly 15–45 seconds unless the user specifies otherwise.

## Rules

- Never pad a Shorts script to reach a target length — cut ruthlessly instead.
- Always front-load the payoff; Shorts viewers decide to keep watching within 1–2 seconds.
- Note where on-screen text/captions should reinforce the hook, since many viewers watch muted.
