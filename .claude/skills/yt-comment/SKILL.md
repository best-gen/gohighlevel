# YouTube Comments

Help drive comment engagement and manage community replies for a video.

## Modes

Infer which the user wants from context, or ask if genuinely ambiguous:

1. **Pinned comment** — write 1–3 short options for the comment the creator pins under their own video. It should do one of: ask an easy, specific question tied to the video's content (to seed engagement), add a useful link/resource, or correct/clarify something in the video. Keep it under ~2 sentences, conversational, first person.
2. **Reply templates** — given a batch of viewer comments (or comment types), draft short, personal-sounding replies for each. Vary phrasing so replies don't look copy-pasted. Group by comment type (question, praise, criticism, spam/troll) and give one strong reply per type, plus specific replies for any actual comments provided.
3. **Comment-bait ideas** — if asked to increase comment volume, suggest 3–5 specific prompts tied to the video's actual content (not generic "comment below!") that invite a real opinion or story.

## Rules

- Never sound like corporate/support-bot copy — match the creator's voice if samples are given.
- Don't respond to hostile/troll comments with defensiveness; suggest either a short disarming reply or "don't engage" when appropriate.
- Keep everything short — comments are skimmed, not read.
