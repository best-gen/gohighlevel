# YouTube Editing Plan

Convert a script/transcript (or a description of raw footage) into an actionable edit plan for the editor (human or AI-assisted).

## What to produce

Walk through the content beat by beat and annotate:

1. **Cut points** — where to trim silence, filler words, false starts, or slow ramps. Be specific ("cut everything before 'so the real question is...'").
2. **Pacing** — flag sections that will feel slow on screen even if they read fine, and suggest tightening (jump cuts, speed ramps) or breaking up with a cutaway.
3. **B-roll / cutaways** — for each beat, suggest what visual should cover the voice (screen recording, stock footage, graphic, photo) so it's never just a static talking head for too long.
4. **Text/graphics** — call out key numbers, quotes, or terms worth putting on screen as text, and where to add lower-thirds or callouts.
5. **Sound design** — note where music should shift energy, where a sound effect punctuates a joke/reveal, and where to duck music under dialogue.
6. **Retention-risk spots** — explicitly flag any point likely to cause drop-off (slow intro, mid-video lull, repeated point) and give a concrete fix.

## Output format

A timestamped or beat-numbered list, one row per beat:
`[beat] — VO/action | cut notes | b-roll | text/graphics | sound`

Keep notes actionable and concrete — an editor should be able to work directly from this without asking clarifying questions.
