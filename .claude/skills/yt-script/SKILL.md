# YouTube Script Writer

Write a complete, read-aloud-ready script for a YouTube video.

## Inputs to gather

Ask only for what's missing and can't be inferred:
- Topic / working title
- Target length (minutes) or word count
- Audience and channel niche
- Tone (educational, entertainment, vlog, etc.)
- Any must-include points, links, or sponsor reads

## Structure to produce

1. **Hook (first 5–15 seconds)** — a specific, curiosity- or stakes-driven opening. No "Hey guys, welcome back" filler. State the payoff or the tension up front.
2. **Setup** — briefly frame what the video covers and why it matters, in one short beat.
3. **Body** — organized into clearly labeled sections/beats (not just one wall of text). Each beat should have a mini-payoff so viewers don't drop off. Write in spoken, conversational language — contractions, short sentences, no essay-speak.
4. **Pattern interrupts** — mark spots (roughly every 30–45s of runtime) where a visual, joke, or tone shift should land, as bracketed notes, e.g. `[cut to B-roll]`, `[beat]`.
5. **CTA / outro** — one clear ask (subscribe, next video, comment prompt) tied naturally to the content, not bolted on.

## Output format

- Deliver the script as plain spoken text with `[bracketed]` production notes inline (b-roll, graphics, emphasis).
- Add an estimated word count / runtime at the top.
- If the requested length is tight, prioritize the hook and highest-payoff beats over completeness.

Do not pad with generic filler to hit a word count — a shorter, tighter script beats a bloated one.
