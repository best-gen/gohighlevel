# YouTube Content Plan

Produce a concrete, prioritized content plan, not a generic idea dump.

## Inputs to gather

- Channel niche/topic and target audience
- Current posting cadence and available production capacity
- Goals (subs, watch time, launch a product, authority-building, etc.)
- Past video performance if available (what's worked)
- Timeframe to plan for (e.g., next 4 weeks)

## What to produce

1. **Content pillars** — 3–5 recurring themes/buckets the channel should rotate through, each with a one-line rationale tied to audience/goals.
2. **Video ideas** — for the requested timeframe, one specific, titled idea per planned upload, tagged with its pillar and an estimated format (long-form, Shorts, live). Ideas should be specific enough to greenlight immediately, not vague topics ("a video about X" is not acceptable — give the actual angle/hook).
3. **Cadence/calendar** — lay ideas out on a simple date or week-by-week grid matching the stated posting frequency.
4. **Series/sequencing logic** — note any ideas that should be ordered (part 1/2, building on a prior video, tied to a seasonal/trend window) and flag time-sensitive ideas.

## Rules

- Prioritize ideas with a clear hook/tension over "safe" generic topics.
- Balance easy/fast-to-produce videos against bigger swings so the plan is actually sustainable.
- If performance data is given, weight the plan toward what's demonstrably worked, but include 1–2 experiments to test new angles.
